# 💰 BudgetAnalyzer

A modern desktop expense tracker built with Python and CustomTkinter.

## ✨ Features

- Add, edit and delete expenses
- Set and manage monthly budget
- Automatic budget balance calculation
- Category-wise spending overview
- Payment method tracking
- Date and time tracking
- Clear all data option
- Local JSON data storage
- Responsive desktop layout
- Modern dark UI

## 🛠️ Tech Stack

- Python
- CustomTkinter
- JSON
- Git & GitHub

  
📁 Data Storage

Expense data is stored locally in JSON files. No external database or online account is required.


## 🚀 Run Locally


git clone https://github.com/pathumnimsara/python-expense-tracker.git
cd python-expense-tracker

# Create and activate the virtual environment:

python -m venv .venv
.venv\Scripts\activate

# Install dependencies:

pip install customtkinter
